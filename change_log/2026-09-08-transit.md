# transit source publication — 2026-09-08

Publish the fixed Ford Transit LKA baseline under Beartech with an additional
2022 firmware matching set. Previously, the fork listed only the author's 2025
Transit firmware versions. The additional set matches `FORD_TRANSIT_MK5` in an
offline exact-match test with fuzzy matching disabled.

## Baseline

- openpilot: `ghostdev137/openpilot` at `8389a6aa3a47611dac70c7864c9f4cf67516d413`.
- opendbc: `ghostdev137/opendbc` at `f4bfa25411755e5ab1aaeaac2b3663b495fd3d59`.
- No later author controller experiments are included.
- The inherited controller, longitudinal behavior, and safety implementation are
  unchanged by the Beartech firmware-recognition addition.

## Publication changes

- Name the source repository and its published branch `transit`.
- Point the opendbc submodule to `beartech-ca/transit-opendbc`.
- Host the current revision's Git LFS assets in `beartech-ca/transit`.
- Update the existing installation helper's repository and branch references.

## Validation and limits

- Ford and generic firmware-fingerprint tests: 21 passed, 138 skipped, and
  2,496 subtests passed.
- Ruff passed for the modified fingerprint table and regression test.
- These are offline software checks. The 2022 matching set still requires live
  openpilot firmware-query confirmation; device installation and on-vehicle
  operation have not been validated.
- No PSCM firmware image or prebuilt device release is included.
